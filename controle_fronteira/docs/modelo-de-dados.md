# Modelo de dados

Tabelas previstas para o MVP:

- `countries`: países fictícios.
- `travelers`: viajantes.
- `documents`: documentos associados a viajantes e países emissores.
- `agents`: agentes que registram decisões.
- `inspections`: histórico de decisões e justificativas.

Os relacionamentos e restrições estão definidos em `sql/schema.sql`.
